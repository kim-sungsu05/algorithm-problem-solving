# [Java]

> **Javaは、エントリーポイントを中心として、役割ごとにモジュール化されたクラスが相互に協調するオブジェクト指向構造で構成されています。**

---

## Javaプログラムの基本構造

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("hello, world!");
    }
}
```

> コード例: [Main](./Main.java) | [Component Class](./Hero.java)

---

* **[class]: Javaは、すべてのコードとデータが必ずclassブロック内に存在しなければならない、クラスベース言語の特性を持っています。**

<br>

* **[public]: publicは公開範囲（アクセス権限）を意味します。privateに設定した場合、JVM（Java実行エンジン）という外部プログラムがコードを実行できなくなります。**

<br>

* **[Main]: Javaは1つのメイン実行ファイルが他のモジュールを参照して実行されます。JVMがプログラムを最初に実行する際、Mainファイルを最初に実行します。クラス名はファイル名と同一の「Main」にする必要があります。**

<br>

* **[static]: staticはメモリへの優先配置を意味します。オブジェクトを生成しなくても、プログラムが実行されるとすぐにメモリへ直接ロードされます。**

<br>

* **[void]: voidはreturnがないことを意味します。Mainファイルの終了はプログラム全体の終了を意味するため、returnが発生することはありません。**

<br>

* **[String[] args]: プログラム起動時に、文字列の配列形式のデータをargsとして受け取ることを意味します。起動時にデータを渡さない場合でも、構文上のルールとして必ず記述する必要があります。なお、argsはメインメソッド専用です。**

<br>

* **[.class]: .classはJavaコードをJVMが解釈できるコードに変換したファイルであり、プログラムのコンパイル時に生成されます。**
