## ✅ Commit Convention

* **コミットメッセージの形式:**
  * solution: アルゴリズム問題の解答
  * fix: バグ・エラーの修正
  * docs: ドキュメントの追加・修正
  * refactor: リファクタリング
  * chore: コードロジックに関係ない環境設定
* **ファイル名の形式:** 'YYYY-MM-DD-テーマ.md' (例: '2026-08-15-Java-oop.md')
